# ZTerminal
<!-- impeccable:product-schema 1 -->

## Platform
Web. Native desktop work is a separate product boundary.

## Users and purpose
People organizing chart, order-flow and Python research work. Opening the app should let them choose their work before presenting a trading terminal.

## Confirmed workflow
The public homepage remains. Open ZTerminal leads to a workspace dashboard. Workspaces open in separate browser tabs, autosave independently and can start as Chart, Order Flow or Python Research. Local use does not require sign-in; cloud synchronization uses the existing verified account and owner boundary. One tab edits a given workspace at a time, with explicit takeover or duplication.

## Constraints
Preserve existing local/cloud work, chart semantics, Python libraries and Helper archives. The dashboard starts no market or Helper connections. Reuse the established ZTerminal visual system and components. No fabricated market data, account state or synchronization claims.
