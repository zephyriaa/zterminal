# Product goal

ZTerminal is an evidence-first quantitative research terminal. It should help a trader decide whether an apparent edge survives scrutiny through exact-source execution, reproducible runs, honest validation, and clear failure analysis.

The research loop is observe → hypothesize → code → backtest → validate → stress test → understand → archive → compare later observation with expectation.

Every displayed result must correspond to its actual strategy source, closed dataset, parameters, runtime, and execution assumptions. Unavailable computation is an explicit failure, never a plausible substitute. Zero, unavailable, failed, and insufficient evidence remain distinct.

Charting supports research; it is not the product moat. Defer marketplace, generic AI generation, broker execution, broad indicator expansion, and prediction-market execution until the validation foundation is trustworthy.
