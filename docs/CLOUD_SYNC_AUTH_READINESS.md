# Cloud sign-in readiness

See [the October 6 authentication and drawing report](AUTH_DRAWING_REBUILD_REPORT.md) for current evidence and validation limits. The October 5 Worker check advertises Google and generates the correct authorization URL; real Google consent and the granted production callback remain unverified. [The September audit](AUTH_AUDIT.md) is historical.

The September audit recorded a `ZTerminal Web` OAuth client in the Google Cloud project `zterminal`, with the Worker origin `https://zterminal-web.zephyria-inc.workers.dev` and its exact `/api/auth/callback/google` callback. It also recorded Testing mode with a restricted test-user list; that console status was not rechecked in this pass. The current authorization handshake confirms the callback URL. The Worker connects to PostgreSQL through Prisma's `pg` driver adapter; its `DATABASE_URL` must be a PostgreSQL connection string. The old document also described a `CLOUD_SYNC_ENABLED` release gate that is no longer present in the code; current enablement is determined by the Google credentials, session secret, public origin, and durable database URL.
