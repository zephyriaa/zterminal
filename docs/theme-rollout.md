# Graphite and violet theme rollout

6 October 2026. Extends the accepted landing palette to documentation (including Python, Windows installation and migration guides), research, download and shared public navigation. Background lighting fades into the reading canvas without a section boundary. Shared controls and headings use violet, graphite and pale lilac.

Public motion is progressive enhancement. One reveal observer handles below-fold sections, keeps restored positions readable and reveals focused content. Lazy-loaded Lenis smooths fine-pointer wheel input; touch and nested readers retain native input. Route changes destroy the scroll instance, and live reduced-motion changes disable both scrolling enhancement and reveals. Landing composition, product captures and educational provenance remain as documented in landing-redesign.md.

The existing appearance store remains canonical, using the same v2 storage key and legacy migration. Violet is the default for fresh workstations. Graphite retains its original persisted key and exact colors, displayed as Classic Blue. Existing saved presets and custom values are preserved; validated colors and bounded numeric preferences reach the chart. A shell-owned bridge applies tokens to terminal chrome and body-mounted portals and cleans them up on unmount. Monaco follows panel and accent choices. Existing chart documents remain authoritative; new documents wait for appearance and document hydration before taking default colors. Explicit appearance changes update the primary chart's presentation without changing drawings, instruments or research data.
