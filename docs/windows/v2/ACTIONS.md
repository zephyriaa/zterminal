# Control contracts and action-to-test map

11 October 2026. This is a proposed implementation contract, not design approval or working product behavior. `control-inventory.csv` gives every rendered candidate an instance ID, source frame/route, rectangle, accessible name, prerequisite, owner, transition, persistence, success/failure, and test contract. `evidence/source/source-inventory.json` preserves the observed DOM, disabled flags, values and text. Static report tabs, grid/replay sliders, study labels, choice cards and table rows are included deliberately. A read-only evidence row is classified as inspection rather than inventing a clickable action.

The census covers 25 specified source compositions and 11 additional source arrangements. It cannot certify the inaccessible Figma descendants, unseen menus, or missing state designs. The approved inventory remains **BLOCKED** until those references and menu contents are reviewed. Every duplicate instance retains its own reference and identity. No preview route transition counts as an implemented import, job, provider, or save.

`observed_name` preserves source labels/text exactly. `accessible_name` supplies the contract name, with proposed labels/corrections explicitly marked where source controls are unnamed or static. This is not an AX certification for every element; static swatches/sliders/study labels need semantic roles and approved names in implementation.

All action families require hover/focus/pressed/selected/disabled/loading/empty/error/recovery coverage where applicable, native accessibility names, success plus failure checks, and restart checks for persistent effects. These are shared obligations, not evidence that variants exist. Specific future tests are tied to instance IDs as `Axx:<instance-id>` in the CSV.

## Required controls without approved visible references

Workspace rename/duplicate/save-as menu; workspace folder picker; import format/picker/cancel/progress and unsupported-format rejection; provider connection/disconnection/subscription/history pagination/cancel/rate-limit; docking resize/reorder/close/link menus and presets; drawing edit/lock/undo/redo menus; indicator add/remove/edit and volume pane; replay pause/stop/range/speed choices; editable source/search/revision menu; true queue cancellation/retry; baseline/candidate selector and incompatibility warning; robustness run/export; full hash expansion and export picker/failure; runtime repair; storage cleanup preview/policy; preference page bodies; shortcut conflict editor; all control-state variants. Their presence is required by the governing brief, but their exact design/location/menu wording is unresolved. These appear as `REQUIRED-*` rows rather than fabricated approved Figma nodes.

`Panel actions`, `Strategy actions`, `Chart layout`, local-workspace menu, timeframe/range choices, theme/density/timezone selectors and speed menus must be audited item by item after design review. No supplied V2 source defines those full menus. The original six visible drawing modes plus magnet/visibility/delete are the concrete drawing inventory; additional unnamed tools cannot be claimed approved.
