# Renderer R0 feature-to-test matrix

11 October 2026. Scope: current dirty tree at `80124f17ae500565fe4bb7a88ad44f4b693d4e02`, native first, independent web second. This is an implementation requirement inventory, not a parity certificate. R1–R7 here are renderer milestones, not V2 product milestones.

Evidence notation: **Observed** means directly viewed in the current application; **Source** means wired in inspected code; **Type only** means an exported/persisted shape without an implemented path. Existing test references passed in R0's 204-test suite unless explicitly stated. Required replacement tests below are **Not Run**, because no replacement was implemented. A source-supported feature is not an interaction or raster pass. Native pixel checks verify non-background pixels, not axes, candle accuracy, font parity or accessibility.

Owners: **D** existing Rust domain/storage/verified data; **G** original C++ transforms/layout/geometry; **N** existing D3D11/WinUI graphics/input/text; **W** future original Canvas 2D; **A** existing ZTerminal algorithm with fixture-verified native port; **S** existing document stores and identity. Every required row must eventually pass native and web acceptance; no permanent disabling to pass. V2 chart requirements come from product-brief journey 5/6, prepared interaction contract and current chart behavior. Original design approval remains separate and blocked for missing references.

**Roadmap/type-only separation:** overlay enum also declares price-line, marker, bubble, range, heatmap, footprint and profile, but only Big Trades is registered in `OVERLAY_REGISTRY`. Standalone CVD/footprint/depth/GEX surfaces are separate observed-data consumers, not implemented chart primitives. Economic-event/liquidation settings explicitly report unavailable. Native login/sync/order execution/provider expansion are outside renderer implementation. Recharts has one unused `src/components/ui/chart.tsx` wrapper and no importing consumer found; preserve it and its dependency as unrelated work. No other charting engine is selected.

**Acceptance limits:** the R0 UI sample directly observed candles, line, volume, EMA/VWAP, axes and disconnected-feed context. It did not execute every drawing/scale/pane/study/export/sync interaction. Those are inventoried from actual implementations with corresponding tests; all replacement raster, mathematical and interaction tests remain Not Run. Missing original Figma exports/approval are Blocked, and saved source captures cannot establish original parity.
